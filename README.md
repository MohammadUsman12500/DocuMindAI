# DocuMindAI

AI Knowledge Base Assistant built with:

- ASP.NET Core Web API
- C#
- SQL Server
- Entity Framework Core
- JWT Authentication
- OpenAI
- Qdrant Vector Database

## Features

- User Authentication
- Document Upload
- PDF/DOCX/TXT Processing
- AI Question Answering
- RAG (Retrieval Augmented Generation)
- Chat History

## Run

```bash
dotnet restore
dotnet ef database update
dotnet run
```
